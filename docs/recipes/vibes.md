# Vibe presets

A vibe sets post-processing, pacing and the music energy curve. It never changes the brand's colours or type.

| Preset | When | Post (`post`) | Pacing | Music |
|---|---|---|---|---|
| **Keynote Dark** | Dev tools, AI, infra, premium launches | `{ "bloom": 0.35, "grain": 0.028, "vignette": 0.16 }` | Slow holds (1.5–2 s); one hero reveal | 96–108 BPM, pad + bass, a riser into the reveal, a sub hit on the logo |
| **Editorial Light** | Consumer apps, B2B SaaS, finance, health | `{ "bloom": 0, "grain": 0.016, "vignette": 0 }` | Calm (1.4–1.8 s holds); generous white space | 80–96 BPM, soft pad + bells, almost no drums |
| **Bold Color** | Creator tools, consumer launches, events | `{ "bloom": 0.15, "grain": 0.02 }` | Brisk (1.0–1.3 s); beat-cut type | 112–124 BPM, kick + hat + pulse, hits on cuts |
| **Calm Product** | Feature updates, changelogs, tutorials | `{ "bloom": 0, "grain": 0.012 }` | Even (1.6–2.2 s); UI-led | 84–92 BPM, pad + arp, gentle ticks on UI events |
