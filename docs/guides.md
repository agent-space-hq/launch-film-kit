# The Launch Film Kit: further-reading guide

Compiled 2026-10-12 for people making brand and launch videos with Claude Opus 5.5 by rendering code (HTML, Canvas, SVG, Three.js, Remotion or HyperFrames) in a headless browser and encoding the frames with ffmpeg.

Most sources were captured 2026-10-11 23:27–23:32 PDT (2026-10-12 06:27–06:32 UTC); the rest were captured later on 2026-10-12. Raw copies are in `research/guides/raw/{aggregators,guides,value,zh}/`. Counts on live sites change daily, so always quote a count with its as-of date. All summaries below are our own wording.

Legend. **Type**: collection / repo / official doc / guide / essay / design system / video. **For**: B = beginner, M = makers who already render video from code, T = technical or harness builders, D = designers.

## Top 10 further-reading picks for the kit

1. @N01ennn, "How to Turn Opus 5.5 Into a Studio" (X, 2026-10-07). The whole method in one place.
2. Anthropic, "Prompting Claude Opus 5.5", the frontend design defaults section. Official advice on avoiding the generic look.
3. HyperFrames docs: the product-launch guide plus the motion prompting and anti-pattern pages.
4. Remotion AI docs (skills and Claude Code plugin), with the licence caveat.
5. OpenChamber Opus 5.5 videos (5,117 indexed), for finding launch-film references by category or stack.
6. Li-Evan/awesome-opus-5.5-video-prompts: 136 verbatim launch prompts, CC BY 4.0 curation.
7. Claude Code docs for `/goal`, `/loop` and `/schedule`, plus the Claude blog "Getting started with loops".
8. Böckeler, "Harness engineering for coding agent users" (martinfowler.com).
9. AutoAE, "Why Claude Remotion videos look flat" (read with vendor bias in mind).
10. Emil Kowalski, "Great Animations" and "Agents with Taste".

Honourable mentions: aiidelist's Opus 5.5 motion design guide (best single beginner page); lemo-opuscar's STYLE.md files; the Skillry original-vs-remake pages.
